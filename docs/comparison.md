# How Forecastle compares

Checked on 2026-11-09. Each of these does something Forecastle does not.

|                                                                                                            | What you forecast                                                                                    | What it asks of you                                           | When you get an answer                                                                                              |
| ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| [Good Judgment Open](https://www.gjopen.com/)                                                              | Real-world questions, scored with Brier scores against the crowd ([FAQ](https://www.gjopen.com/faq)) | An account                                                    | When the event happens or the data is released; each question sets its own date ([FAQ](https://www.gjopen.com/faq)) |
| [Superforecasting Fundamentals](https://good-judgment.thinkific.com/courses/Superforecasting-Fundamentals) | A course that teaches forecasting                                                                    | $99.00                                                        | As you work through it                                                                                              |
| [TimeGPT](https://nixtla.io/docs/introduction/introduction/faq.md)                                         | A hosted forecasting model for your own series                                                       | Registration and an API key; a self-hosted version on request | When the API answers                                                                                                |
| [GIFT-Eval](https://github.com/SalesforceAIResearch/gift-eval)                                             | You don't: it ranks forecasting models against each other across many datasets                       | A model to submit                                             | On its public leaderboard                                                                                           |
| Forecastle                                                                                                 | The next seven days of one daily chart, against one open model                                       | Nothing for the game; uv for `custom`                         | When you hand it in, for daily puzzles; after the scored week, for live rounds                                      |

Forecastle covers one narrow question, the next week of one chart, and scores you against the same open model every time.
